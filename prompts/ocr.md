# 用户提示词

## 美团余额明细图片识别
### 数据提取规则

#### 交易记录识别
- 识别每笔交易的描述信息（如"【9.9喝咖啡】美式咖啡/拿铁咖啡2选1"）
- 识别交易时间（格式：MM-DD HH:mm:ss 或 YYYY-MM-DD HH:mm:ss）
 - 如果是没有YYYY数据，则在这批交易上方显示为YYYY年M月
- 识别交易金额（格式：+/-数字.数字，如"+4.20"或"-4.20"）
- 识别交易类型（根据描述判断，如"消费"、"退款"、"充值"等）

#### 时间处理
- 如果图片中显示的是相对时间（如"05-13"），需要根据交易上方显示的年份补充完整日期
- 时间格式统一为：YYYY-MM-DD HH:mm:ss

#### 金额处理
- 正数表示收入/退款：4.20（JSON中直接写数字，不加+号）
- 负数表示支出：-4.20
- 去除货币符号，保留数值

#### 交易类型判断
- 根据交易描述判断类型：
  - 包含"退款"、"余额退款" → "退款"
  - 包含"充值"、"消费充值" → "充值"
  - 包含"提现"、"余额提现" → "提现"
  - 其他消费类描述 → "消费"

### 字段说明
  - `amount`: 交易金额（数字，正数表示收入，负数表示支出，JSON格式中不加+号）
  - `type`: 交易类型（消费、退款、充值、提现等）
  - `name`: 交易描述
  - `date`: 交易时间（YYYY-MM-DD HH:mm:ss，字符串格式）

### 注意事项

1. 确保识别所有可见的交易记录，不要遗漏
2. 时间格式要准确，注意年份的补充
3. 金额要准确识别正负号
4. 交易类型要根据描述合理判断
5. 如果图片中有多个月份的数据，需要按时间顺序排列
6. 如果某些信息无法识别，用空字符串或null表示，但不要跳过整条记录
