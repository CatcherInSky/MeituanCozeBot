# 美团退款核查助手
## 使用方法
1. 上传美团账单csv格式文件到左侧区域
2. 点击左侧确认按钮，等待工作流处理csv文件，处理结束后查看需要上传哪些渠道哪些时间的交易记录
3. 上传对应的交易记录到右侧区域
4. 点击右侧确认按钮，等待工作流处理交易记录文件，处理结束后查看确认交易记录可以覆盖美团账单的时间
5. 点击分析数据按钮，等待工作流分析
6. 点击查看数据查看分析后的数据详情，包括需要人工核查的订单、未匹配的订单以及已匹配的订单
7. 拿未匹配记录的交易单号去找美团客服咨询
8. 左下角的下载原始数据按钮可以csv格式下载数据，方便人工再次核查



## 叠甲声明
1. 未匹配可能有多种原因导致，找客服之前可以先自己确认一下
- 同一个支付渠道有多个账户，只传了其中一个的交易记录
- 非人民币场景
- 单渠道多卡（如有多张同一银行的信用卡）
2. 目前支持渠道包括：支付宝、招商银行储蓄卡、招商银行信用卡、广发银行信用卡、微信支付，美团余额和美团月付无法导出文件格式的账单，只能调用ocr，但是速度和准确度都一般，请酌情使用
3. 中国银行储蓄卡导出的账单是加密pdf，难以解析；其他渠道由于本人没有开户，没有实际账单文件无法保证解析质量，所以暂不支持
4. 本人不收集上传的所有信息，工作流中所有的方法在[github](https://github.com/CatcherInSky/MeituanCozeBot)中开源，大家可以帮忙code review，起到监督作用
5. 但本人不清楚coze会拿数据做什么，详情参考coze的隐私政策
